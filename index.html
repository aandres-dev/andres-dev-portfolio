The Operating Protocol

The Machine: How I Direct

Precision engineering without guesswork. The Spec-Driven Development (SDD) cycle.

01 / PROPOSE

Intent & Blast Radius

Define the problem boundary, evaluate architecture tradeoffs, and outline the blast radius before writing a single line of implementation.

02 / SPECIFY

Formal Scenarios

Write testable specifications using Given/When/Then and RFC 2119 keywords. Strict contracts remove all ambiguity from AI models.

03 / DESIGN

Clean Architecture

Enforce hexagonal boundaries, container-presentational separation, and data flow contracts with comprehensive sequence diagrams.

04 / VERIFY

Adversarial Audits

Execute test runners, linters, and stress audits. No task merges without empirical proof of correctness and zero attribution clutter.
